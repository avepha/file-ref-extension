# Security Policy

## Supported Versions

Security fixes are provided for:

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| `main` | Yes |
| Older releases | No |

## Reporting a Vulnerability

Please do not open a public issue for suspected vulnerabilities.

Send a report through GitHub's private vulnerability reporting flow for this repository, or email the maintainer listed in the repository profile if private reporting is temporarily unavailable. Include:

- A short description of the issue and affected files or commands
- Reproduction steps or a proof of concept
- Expected impact and any prerequisite conditions
- Suggested remediation if you have one

You can expect an initial acknowledgement within 5 business days. After triage, fixes will be prepared privately when needed and disclosed once a patch or mitigation is available.
